# Research Assistant

A command-line research assistant that uses an OpenAI model, web search, and Wikipedia to answer research queries. Results are saved to `research_output.txt`.

## Requirements

- Python 3.10+
- An OpenAI API key

## Setup

From the project directory, create and activate a virtual environment:
pip install -r requirements.txt

## Run 
python main.py

```powershell
python -m venv .venv
